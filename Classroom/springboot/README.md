# Capgemini Training Repository

This repository contains the code and materials created during my **Capgemini training program**. It is organized into two main folders that include the work completed during the training sessions and practice assignments.

## 📁 Folder Structure

### 1. Classroom

This folder contains the code written during the **classroom training sessions**. These programs were implemented while learning different concepts, understanding examples, and practicing them in real time.

### 2. Assignment

This folder includes the **assignments given during the training**. These programs were written independently to apply the concepts learned in the classroom sessions.

## 📌 Purpose

The purpose of this repository is to:

* Keep track of the code written during the training.
* Practice and strengthen programming concepts.
* Maintain a structured record of classroom examples and assignment solutions.
